# Beginning Statistics

Statistics begins with questions about the world: What is typical? How much do observations vary? What can a sample tell us about a population?

This book develops the tools to answer those questions, from organizing a small data set to estimating population characteristics, testing hypotheses, and fitting a regression line. Worked examples introduce each method, followed by practice exercises and the source edition’s selected answers.

## Reading the book

Begin with [Introduction](chapters/ch-01-introduction.md), then work through [Descriptive Statistics](chapters/ch-02-descriptive-statistics.md) and [Basic Concepts of Probability](chapters/ch-03-basic-concepts-of-probability.md). The remaining chapters develop random variables, sampling, estimation, hypothesis testing, two-sample methods, regression, and chi-square and F-tests.

Use the [statistical reference tables](appendices/appendix.md) when a worked example or exercise calls for a binomial, normal, t, chi-square, or F-distribution table. Answer sections expand when selected; the source supplies selected answers and leaves some numbered answer slots empty.
